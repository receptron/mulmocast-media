# Sound Effects — Sources and Licenses

Where every file in this folder came from and under what license. For what the sounds are,
see [README.md](README.md).

## Policy

Only add sounds that we may redistribute (CC0 or equivalent). Keep the original license file
next to the sounds and add a row to the table below. Sounds that are free to *use* but not to
*redistribute* (Pixabay, 効果音ラボ, Sonniss GDC bundles, BBC Sound Effects, …) must not be added.

# Avatars

Talking avatars for [AvatarScript](https://github.com/receptron/avatarscript) and MulmoCast
(`speechParams.speakers.<name>.avatar.source`). Each folder is an AvatarScript avatar package:
`avatar.json` (manifest), `rig.json` and `built/` (mesh layers and drawn eye/mouth sprites).
